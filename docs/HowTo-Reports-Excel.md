# Rapports PDF et Excel

Les rapports planifiés ou lancés manuellement produisent maintenant un PDF et un classeur Excel (`.xlsx`). Si une adresse de destinataire est configurée, les deux fichiers sont joints au courriel.

## Comparaison de périodes

Dans les propriétés d’un tableau de tags, activez **Comparer à la période précédente** pour les périodes jour, semaine ou mois. Le rapport compare la période sélectionnée à la période calendrier immédiatement précédente :

- jour précédent pour un rapport journalier;
- semaine précédente pour un rapport hebdomadaire;
- mois précédent pour un rapport mensuel.

Le tableau ajoute, pour chaque tag, les colonnes de la période courante, de la période précédente et de l’écart numérique. La comparaison n’est pas proposée pour une plage ponctuelle.

## Classeur Excel

Le classeur contient un onglet **Summary** et des onglets distincts pour les tableaux de tags, les historiques d’alarmes et les séries de courbes. Les valeurs numériques reconnues sont écrites comme nombres Excel. Les fichiers PDF et Excel apparaissent ensemble dans la liste des rapports générés et peuvent être téléchargés séparément.

Les rapports existants restent compatibles : la comparaison est désactivée par défaut pour leurs tableaux; ils continuent toutefois à produire les deux formats.
